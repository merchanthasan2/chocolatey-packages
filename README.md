# Chocolatey Packages

Chocolatey package sources for **NetSpeed Boss**.

## Install

```powershell
choco install netspeedboss
```

## Publishing

1. Add a repository secret named `CHOCOLATEY_API_KEY` from your [Chocolatey account](https://community.chocolatey.org/account).
2. Trigger the **Pack and Publish Chocolatey Package** GitHub Action (or push a change under `netspeedboss/`).
